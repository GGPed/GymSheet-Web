# GymSheet Web 0.2.0-alpha.4 — Master handoff
- Modali consultative condivise per menu, Mobilità, immagini, note e riepilogo: X, scroll, focus e ritorno alla schermata sottostante; nessuna minimizzazione. Il timer conserva il pattern persistente.
- Aggiunta settimana con conferma numerata e annullamento senza creazione.
- Archivio dentro la sezione menu, date di fine persistite al nuovo import e conservate nei backup. Le vecchie date mancanti sono indicate come non registrate, senza dedurle dai workout.
- Import con export consigliato prima del file picker, restore spiegato, notifiche ON/OFF con info; icone coerenti e senza chevron ridondanti.
- Progressi in accordion A/B/C aperti all'atterraggio, Mobilità esclusa anche dal report condiviso; icona download PDF e legenda reps.
- Recupero in linguaggio naturale, riepilogo con giorno/stato/serie oltre a durata, miglioramenti concreti, settimana e streak.
- Prescrizioni singole a tempo e superserie miste: timer, reps e kg soltanto quando previsti; stato locale preservato.
- Verifiche superate: TypeScript/build PWA, Excel reale diretto, settimane/progressi/streak/report, backup/restore e rollback, snapshot, date archivio, modali, timer, launcher IP dinamico e controlli mobile 390x844.
- Account, cloud, tutorial e nuove immagini Mobilità restano fuori scope.
